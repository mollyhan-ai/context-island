# 语境岛界面规范

参考：[Refero 整理的 Duolingo 风格](https://styles.refero.design/style/7088d695-362b-4e09-b325-fa8136d4f350)。该页面是第三方提炼的风格参考，不是语境岛的产品需求，也不是 Duolingo 官方设计文档。

## 设计方向

借鉴圆角组件、清晰的按钮层级与 4px 间距网格。语境岛采用淡灰绿色背景、深绿色主操作和适合英文阅读的衬线字体，形成轻松、安静的学习界面。

## 字体和颜色

| 内容 | 本地预览规格 |
| --- | --- |
| 界面文字 | 系统中文无衬线字体，正文 16px |
| 板块标题 | 18px，字重 700 |
| 卡片单词 | Georgia / Iowan Old Style，22px |
| 英文例句 | 20px；窄屏 18px |
| 音标、小喇叭 | 16px |
| 辅助操作 | 14px；“换一批”采用蓝色文字 |

沿用现有纸张色、深绿正文、灰绿辅助文字及各句子成分的语义色。英式发音为蓝色，美式发音为红色。

## 组件和间距

- 间距基准为 4px，常用 8、12、16、24px。
- 搜索框、搜索按钮、领域选择器和推荐词按钮使用 12px 圆角；描边控件采用 2px 边框。
- 卡片采用 16px 圆角，桌面内边距 20px，窄屏 16px。
- 搜索框与搜索按钮最小高度 48px；常用操作的点击高度至少 44px。
- 没有搜索结果时，常见词板块与搜索区域间距为 24px。
- 卡片标题下外边距为 0，音标行下外边距为 4px；保留发音按钮的点击区域。
- 推荐词每批 12 个，各领域三批；“换一批”位于板块标题右侧。
- 常见词按钮组与下方分隔线之间留白为 24px。
- 音标和整句发音保持图标操作，不添加播放状态边框和常驻播放文案；键盘焦点仍可辨认。

## 评审约定

参考页中的营销大标题、宽屏布局和大段留白不直接套用到查词页。每次设计修改先在本地预览，用户确认后再发布。
