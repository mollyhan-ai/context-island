## 4. 实测发现的技术冲突

阶段文档 2.2 / 3.1 声称：不保留 WordNet 语料，运行时仍可使用 NLTK 词形还原。技术适配声明指定的却是 `WordNetLemmatizer`。

**在全新进程中把语料路径限定为空目录，执行 `WordNetLemmatizer().lemmatize('banks', 'n')`，实际得到 `LookupError`。** 保留语料时返回 `bank`。NLTK 官方说明也指出该还原器调用 WordNet 语料 reader 的 `_morphy`。[NLTK WordNetLemmatizer](https://www.nltk.org/api/nltk.stem.wordnet.html)

因此“只把义项展平进 SQLite”不能使现有还原器脱离语料。本次保留完整语料建立**可运行基线**，未把去语料的残缺包作为优化结果。建议先用本探针补完云端实测，再根据数字确定：保留语料，或在构建期额外导出词形词典/异常表并验证独立还原实现。后者需要明确的数据契约与一致性验证，不是本次可以顺带完成的删文件优化；模型也不能替代此项确定性能力。
